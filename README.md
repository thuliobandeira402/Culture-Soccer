# Culture-Soccer
Jogo onde 2 players disputam sobre a cultura de algum país, cobram penalti e pontuam
Menu Inicial: Pressione G para começar.

Seleção de País: Use as teclas numéricas de 1 a 6 para escolher sua seleção.

Dificuldade: Escolha entre 1 (Fácil), 2 (Médio) ou 3 (Difícil).

Respostas: Utilize as teclas A, B, C ou D para responder às perguntas de múltipla escolha.

Pênaltis:

Chutador: Teclas A (Esquerda), S (Meio), D (Direita).

Goleiro: Teclas H (Esquerda), J (Meio), K (Direita).# ⚽ Culture Soccer

**Culture Soccer** é um jogo competitivo local para dois jogadores que une conhecimentos gerais sobre cultura mundial com a emoção de uma disputa de pênaltis. Desafie os seus amigos, responda corretamente para ganhar a chance de chutar e mostre quem é o mestre do campo e dos livros!

---

## 🚀 Sobre o Projeto

O jogo foi desenvolvido em **Python** utilizando a biblioteca **Pygame**. A dinâmica é dividida em dois momentos principais:
1.  **O Desafio Intelectual:** Os jogadores devem responder perguntas sobre a cultura do país selecionado.
2.  **A Decisão no Campo:** Se acertar a pergunta, o jogador ganha o direito de realizar uma cobrança de pênalti animada contra o oponente.

---

## 🎮 Como Jogar

### Pré-requisitos
* Python 3.x instalado.
* Biblioteca Pygame instalada:
    ```bash
    pip install pygame
    ```

### Comandos
1.  **Menu Inicial:** Pressione `ENTER` para começar.
2.  **Seleção de País:** Use as teclas numéricas de `1` a `6` para escolher a sua seleção.
3.  **Dificuldade:** Escolha entre `1` (Fácil), `2` (Médio) ou `3` (Difícil).
4.  **Respostas:** Utilize as teclas `A`, `B`, `C` ou `D` para responder às perguntas de múltipla escolha.
5.  **Pênaltis:**
    * **Chutador:** Teclas `A` (Esquerda), `S` (Meio), `D` (Direita).
    * **Goleiro:** Teclas `H` (Esquerda), `J` (Meio), `K` (Direita).

---

## 🛠️ Estrutura do Código

O projeto está organizado para facilitar a manutenção e expansão de conteúdo:

* `game.py`: Arquivo principal contendo o loop do jogo e a lógica de estados.
* `utils/utils.py`: Funções auxiliares para carregamento de perguntas, verificação de respostas e gerenciamento de sons.
* `images/`: Contém todos os recursos visuais, incluindo *spritesheets* dos jogadores e fundos dos menus.
* `audio/`: Efeitos sonoros de chutes, gols e trilha sonora de fundo.

---

## 🌟 Funcionalidades

* **Multiplayer Local:** Sistema de turnos entre Jogador 1 e Jogador 2.
* **Sistema de Rounds:** Partidas estruturadas em 6 rodadas para definir o vencedor.
* **Animações Dinâmicas:** Sprites animados para jogadores de diferentes nacionalidades (Brasil, Espanha, Argentina, França, Japão e Inglaterra).
* **Feedback Sonoro:** Sons imersivos que reagem às ações do jogador (cliques, gols e defesas).
